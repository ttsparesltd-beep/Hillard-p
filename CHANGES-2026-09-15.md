# Service history + invoice allocation — 15 Sep 2026

## Customer app
- **History tab removed** from every bottom nav (Garage / Invoices / Calendar / Account).
- **Service History bar on each car** in the garage (index.html) — shows "3 records · 2 invoices",
  opens hillard-service-history.html?vehicle=… : one timeline of work done + invoices for that car.
- **Add work done elsewhere** lives on the car's history page and returns there after saving.
- **Invoices** show the plate straight off the invoice (vehicle_id) and mileage where known.
- **PDF opening fixed on iPhone** — the tab is opened inside the tap, then pointed at the signed URL.

## Admin (hillard-admin.html)
- Access is decided by the `staff` table (same as the database), not a hard-coded email list.
- Invoices: "No vehicle (n)" filter and stat card. Unallocated rows show **Allocate · PLATE**.
- **Allocate panel**: shows what Zoho said, detects the plate, searches your cars, or adds the car
  (DVLA lookup) with an existing or brand-new owner, then links the invoice. customer_id follows the
  vehicle's owner. Mileage on the invoice updates the car's last_mileage if higher.
- Admin PDF button opens the real Zoho PDF from the private bucket.

## Admin hub (hillard-admin1.html, also at /admin)
- Signed-in status bar + links to Dashboard, Job sheets, Break appraisals.

## Database (already applied — SQL in supabase/migrations/20260915_invoice_allocation.sql)
- invoices.detected_plate + indexes.
- Triggers: a customer created in admin with an email is linked automatically when that email
  signs up (and vice-versa).

## Sync (supabase/functions/zoho-invoice-sync — v3, deployed)
- Plate detection handles current / prefix / suffix / dateless formats; reference field wins over
  customer name. Mileage only from "…miles" or plate+number, so job refs like LW-6833 stay out.
- Existing rows are refreshed first; new PDFs capped at 60 per run so it never times out.
- Rows with a plate but no car are re-checked every run: add the car in admin and its invoices link
  themselves within 30 minutes.
